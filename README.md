# Гардероб Аси

Цифровой гардероб в ретро-стиле: листаешь верх, низ, обувь и сумки, жмёшь «рандом», а «надень меня» собирает образ на манекене.

Работает без сервера, просто как статические файлы (GitHub Pages).

## Как добавить вещь

1. Сфоткай вещь на ровном фоне и убери фон (remove.bg или «Удалить фон» в Фото на айфоне). Сохрани как PNG.
2. Положи файл в `items/`, например `items/top-sweater.png`.
3. Добавь строку в `wardrobe.js`:
   ```js
   { cat: "top", name: "серый свитер", img: "items/top-sweater.png" },
   ```
   Категории: `top`, `bottom`, `shoes`, `bag`.
4. Открой «Надень меня» → «Подогнать», тапни вещь и подвинь или увеличь её на манекене. Положение запоминается в браузере.

Чтобы вместо манекена была Ася, положи её фото в полный рост (без фона, примерно 2:5) и укажи `model: "items/asya.png"`.
