# Гардероб Аси

Цифровой гардероб в ретро-стиле: листаешь верх, низ, обувь и сумки, жмёшь «рандом», а «надень меня» собирает образ на манекене.

Работает без сервера, просто как статические файлы (GitHub Pages).

## Облако (Supabase)

Вещи, фото и лукбук хранятся в Supabase и одинаковые на всех устройствах. Доступ только по паролю.

1. Создать проект на supabase.com.
2. SQL Editor → вставить `supabase.sql` → Run.
3. Authentication → Users → Add user → Create new user (почта + пароль, «Auto confirm»). Сделать аккаунт для Аси (и себе).
4. Authentication → Sign In / Providers → выключить «Allow new users to sign up».
5. Project Settings → API: вписать Project URL и anon/publishable key в `config.js`.

Пока `config.js` пустой, сайт показывает демо-гардероб с нарисованными вещами.

## Как добавить вещь

Войти → «+ вещь» → сфоткать или выбрать фото → фон убирается автоматически (нейросеть прямо в браузере, первый раз скачивается ~40 МБ) → категория, название → «в гардероб».

Если фон не убрался: на айфоне в «Фото» зажать вещь → «Поделиться» → сохранить картинку уже без фона, и загрузить её.

Новая вещь сама садится по фигуре: брюки от талии до щиколоток, верх от плеч до бёдер и т.д. Потом «надень меня» → «подогнать»: тапнуть вещь и подвинуть пальцем или кнопками; ↔ уже/шире и ↕ короче/длиннее меняют ширину и длину отдельно, ↺ возвращает автоматическую посадку. Там же «моё фото» — поставить фото Аси вместо манекена (в полный рост, стоя прямо).

## Сезоны, погода, категории

- Категории: верх, второй слой (жилетки, кардиганы, рубашки нараспашку — между верхом и курткой), низ, платья (вместо верха и низа), верхняя одежда, головные уборы, обувь, украшения, сумки. Верхнюю, головные и украшения можно не надевать («— без —»).
- У вещи можно отметить сезоны (ничего не отмечено = всесезонная). Плашка сезона вверху фильтрует гардероб, клавиша S.
- «☀ что надеть сегодня» берёт погоду (Open-Meteo, по геолокации или городу, 📍 — сменить город) и собирает образ: сезон по ощущаемой температуре, куртка в холод или дождь, шапка в мороз, напоминание про зонт.
- «Надень меня» → «коллаж»: вещи раскладываются как коллаж в Pinterest, ↻ — другая раскладка, «двигать» — расставить вещи вручную (тап — выбрать, палец — двигать, два пальца или −/+ — размер, ↺ — как было), «сохранить фото» — картинка для сторис. Раскладка сохраняется вместе с образом в лукбуке. Лукбук показывает образы в выбранном виде.
- ✎ на карточке — поменять название, категорию, сезоны, цвет и фото (нажать на фото → выбрать новое; фон уберётся, цвет и посадка пересчитаются).
- Вкладка «шкаф»: все вещи по категориям; тапни, что хочешь надеть (платье заменяет верх и низ), и жми «надеть» — откроется примерочная. «✨ подобрать к выбранному» — оставляет выбранные вещи (например, юбку) и подбирает к ним остальное по правилам цветов; жми ещё раз — другой вариант.

Если база создавалась до этого обновления, один раз выполнить `migration-3.sql` в SQL Editor.

## Цвета и сочетания

По статье Guess «Как сочетать цвета в одежде» (`colors.js`):

- Цвет каждой вещи определяется по фото сам (кружок у карточки), поправить — ✎ → «цвет»; первый выбранный — главный, остальные — цвета принта.
- Образ оценивается по правилам: 2–4 цвета, нейтральная база (белый, чёрный, серый, бежевый…), правило 60-30-10, не больше одного яркого цвета, яркое — точечно в аксессуарах или ярким верхом к спокойному низу, схемы круга Иттена (монохром, аналоговая, комплементарная с контрастом в акценте, триада), пары из статьи (бордовый + чёрный/молочный/тёмно-синий/коричневый, синий + белый/серый/бежевый/коричневый/деним, коричневый + молочный/песочный/голубой/тёмно-синий, голубой + бежевый/белый/серый…), однотонные вещи в цветах принта.
- «Рандом» и «что надеть сегодня» перебирают сотни вариантов и берут самые гармоничные; строка под шапкой показывает схему и палитру.
- Лукбук → «✨ собрать лукбук по цветам»: 6 разных образов в разных схемах, с подписью схемы. Учитывает фильтр сезона.

Для облака один раз выполнить `migration-5.sql` (добавляет колонку цветов; включает прошлые обновления).

## Telegram-бот «образ на сегодня»

Каждое утро в 08:07 (МСК) GitHub Actions (`.github/workflows/daily-lookbook.yml`) запускает `bot/daily.mjs`: погода → 3 разных образа по тем же правилам, что на сайте → коллажи → альбом в Telegram.

Настройка (один раз):
1. В Telegram у @BotFather: `/newbot` → получить токен.
2. Ася открывает бота и жмёт «Старт».
3. В Supabase → Authentication → Users → Add user: аккаунт для бота (почта + пароль, Auto Confirm).
4. В GitHub → Settings → Secrets and variables → Actions → New repository secret: `TELEGRAM_BOT_TOKEN`, `BOT_EMAIL`, `BOT_PASSWORD`.
5. Actions → «Образ на сегодня в Telegram» → Run workflow → mode `chats`: в логе будет chat id Аси → секрет `TELEGRAM_CHAT_ID` (можно несколько через запятую).
6. Run workflow → mode `send` — проверить. Город: Variables → `CITY` (по умолчанию Москва), число образов — `OPTIONS`.

Проверка без отправки: `cd bot && npm ci && cd .. && DEMO=1 DRY_RUN=1 node bot/daily.mjs` → картинки в `bot/out/`.
